# Закидушка

Приложение для macOS, чтобы закидывать на Android-планшет фильмы, картинки
и вообще любые файлы — по кабелю или по Wi-Fi. Перетащил из Finder в окно —
файл уже на планшете. Обратно тоже работает: из окна в Finder.

Интерфейс как у файлового менеджера: слева планшеты и быстрые места
(«Фильмы», «Картинки», «Загрузки», «Камера», SD-карта), справа содержимое папки.

## Что умеет

- Перетаскивание файлов и папок из Finder в окно — копирование на планшет.
  Можно бросить прямо на «Фильмы» или «Картинки» в боковой панели.
- Перетаскивание из окна в Finder — копирование на Mac.
- Перед копированием проверяет место на планшете и спрашивает, если такие файлы
  уже есть («Заменить» / «Скопировать только новые»).
- Очередь с прогрессом, скоростью и оставшимся временем; отмена, повтор, «Остановить всё».
- Скопированные фото и видео сразу видны в «Галерее» и плеерах: приложение
  просит Android проиндексировать их, не дожидаясь пересканирования.
- Новая папка, переименование, удаление, фильтр по имени, сортировка.
- Свободное место на памяти планшета видно всегда.
- Один планшет по кабелю и по Wi-Fi одновременно показывается одной строкой; копирование
  идёт по кабелю (он быстрее). Если кабель выдернуть, следующие файлы пойдут по Wi-Fi,
  а прерванный можно повторить одной кнопкой.

## Как подключить планшет

Работает через adb — стандартный канал отладки Android. На планшете это
включается один раз:

1. **Настройки → Сведения о планшете → Сведения о ПО** — семь раз нажать «Номер сборки».
2. **Настройки → Параметры разработчика** — включить «Отладка по USB».
3. Подключить кабель, на планшете отметить «Всегда разрешать с этого компьютера» и нажать «Разрешить».

### Wi-Fi

Кнопка **Wi-Fi** внизу боковой панели (или ⌘K):

- **Через кабель** — планшет на проводе, одна кнопка «Включить Wi-Fi», и кабель можно убрать.
  Работает до перезагрузки планшета; Закидушка запоминает адрес и подключается сама.
- **QR-код** (Android 11+) — без кабеля вообще: на планшете «Отладка по Wi-Fi» →
  «Подключить устройство с помощью QR-кода», навести камеру на код в окне.
- **Код** — то же, но вводом шестизначного кода с экрана планшета.

Mac и планшет должны быть в одной сети. По кабелю копирование заметно быстрее:
на Galaxy Tab Active4 Pro — около 33 МБ/с, фильм на 4 ГБ копируется примерно за две минуты.

## Требования

macOS 14+. Нужен adb (Android Platform Tools). Приложение само находит его в
Android Studio (`~/Library/Android/sdk`), Homebrew или `PATH`; если не нашло —
предложит скачать с сайта Google (≈15 МБ). Либо:

```
brew install --cask android-platform-tools
```

## Сборка

```
./build.sh
```

Собирает `build/Закидушка.app` (SwiftPM + SwiftUI, без внешних зависимостей,
ad-hoc подпись). Перенести в программы: `cp -R "build/Закидушка.app" /Applications/`.

## Как устроено

Приложение не вызывает `adb push` / `adb pull`, а само разговаривает с adb-сервером
через его сокет (127.0.0.1:5037) — так есть точный прогресс, мгновенная отмена
и никаких проблем с пробелами, кавычками и кириллицей в именах.

| Файл | Зачем |
| --- | --- |
| `Core/ADBSocket.swift` | соединение с adb-сервером, его протокол «смарт-сокетов» |
| `Core/Sync.swift` | протокол `sync:` — список, stat, отправка и приём файлов (64-битные размеры) |
| `Core/Shell.swift` | команды на планшете через shell v2: отдельные stdout/stderr и код выхода |
| `Core/ADBTool.swift` | поиск adb, запуск сервера, скачивание Platform Tools |
| `Core/DeviceHub.swift` | список планшетов (`track-devices`), Wi-Fi через `adb tcpip`, автопереподключение |
| `Core/Pairing.swift` | сопряжение по QR-коду и коду (Android 11+) |
| `Core/Session.swift` | папки, очередь передач, место на диске, индексация медиа |
| `UI/*` | окно, боковая панель, таблица файлов, полоса передач, окно Wi-Fi |

## Тесты

```
swift test
```

Логика (разбор ответов adb, план загрузки, форматирование) проверяется без устройства.
Если подключён планшет или эмулятор, дополнительно гоняются живые тесты: отправка и
приём с побайтовой сверкой, кириллица и кавычки в именах, отмена посреди передачи
(частичный файл не остаётся), и полный путь через приложение — загрузка папки,
вопрос о замене, скачивание обратно, удаление. Живые тесты пишут только в
`/data/local/tmp` и не трогают файлы на планшете. Выбрать устройство:
`ZAKIDUSHKA_SERIAL=emulator-5554 swift test`.
